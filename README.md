# JRP AI Blogger

## How to Run the Project

This project uses Streamlit for the user interface. Follow the steps below to run the project:

### Prerequisites

1. **Python**: Ensure you have Python installed on your machine. You can download it from [python.org](https://www.python.org/).
2. **Streamlit**: Install Streamlit if you haven't already. You can install it using pip:

    ```sh
    pip install streamlit
    ```

### Running the Project

1. **Navigate to the project directory**: Open your terminal and navigate to the directory where `streamlit_ui_capstone.py` is located.

    ```sh
    cd path/to/your/project
    ```

2. **Run the Streamlit application**: Use the following command to start the Streamlit application:

    ```sh
    streamlit run streamlit_ui_capstone.py
    ```

3. **Access the application**: Once the server is running, open your web browser and go to the URL provided by Streamlit (usually `http://localhost:8501`).

### Additional Information

- **Stopping the server**: To stop the Streamlit server, go back to your terminal and press `Ctrl+C`.
- **Dependencies**: Make sure to provide your API key in the `streamlit_ui_capstone.py` file.

That's it! You should now be able to run and interact with the JRP AI Blogger project.
